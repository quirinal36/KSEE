# 4. 학술대회 및 참가신청

## 4.1 기능 설명

국내 학술대회와 한중일 학술대회를 목록/상세로 제공하며, 행사별 접수 기간에 참가신청을 받는다. 행사 상세 콘텐츠는 유형 탭과 언어별 데이터로 구성된다.

| 기능 | URL | 설명 |
|---|---|---|
| 행사 목록 | `GET /symposium/`, `/symposium/domestic`, `/symposium/international` | 행사 유형별 목록 및 페이징 |
| 행사 상세 | `GET /symposium/{where}/view/{id}[/{tab}]` | 조회수 증가, 현재 언어의 상세 탭/사진 표시 |
| 참가신청 화면 | `GET /symposium/apply/{id}` | 회원 정보 기본 표시 및 접수 기간 확인 |
| 신청 저장 | `POST /symposium/apply` | 중복 신청 확인 후 저장, 첨부파일 연결 |
| 신청 조회 | `GET/POST /symposium/apply/search` | 행사와 신청자 조건으로 신청 건 찾기 |
| 신청 상세/수정/삭제 | `/symposium/apply/view/{id}`, `/edit/{id}`, `POST /edit`, `POST /delete` | 신청자가 신청 내용을 관리 |

## 4.2 참가신청 안내

참가신청은 다음과 같이 진행합니다.

1. [국내 학술대회](/symposium/domestic) 또는 [국제 학술대회](/symposium/international)에서 신청할 행사를 선택합니다.
2. 행사 상세 페이지에서 **참가신청** 버튼을 선택합니다.
3. 접수 기간이라면 신청 정보와 필요한 첨부파일을 입력한 뒤 신청을 완료합니다.
4. 접수 기간 전이거나 마감된 경우에는 해당 안내가 표시되며 신청서를 작성할 수 없습니다.
5. 이미 같은 행사에 신청한 경우에는 중복 신청 안내가 표시됩니다.
6. 신청이 완료되면 [참가신청 조회](/symposium/apply/search)에서 신청 내용을 확인하고 수정하거나 취소할 수 있습니다.

## 4.3 입력 데이터 명세

| 구분 | 필드 |
|---|---|
| 행사 | 제목, 장소, 영문 제목/장소, 시작/종료일, 접수 시작/종료일, 유형 |
| 행사 상세 | 행사 ID, 상세 유형 탭, 언어, 제목/내용, 연결 사진 |
| 참가신청 | 행사 ID, 회원 구분, 발표자 여부, 국적, 성명, 소속, 직위, 연락처, 이메일, 첨부파일 ID, 상태 |

## 4.4 처리 규칙

- 행사 목록은 국내(`sympType=1`)와 국제(`sympType=2`)로 나뉜다.
- 상세를 열면 행사 조회수가 증가한다.
- 지정 탭의 언어별 상세 내용이 없고 다른 상세 탭이 있으면 첫 상세 탭으로 이동한다.
- 신청 화면은 `applyStart`~`applyFinish` 바깥일 때 접수 전 또는 마감 상태를 표시한다.
- 이미 신청한 경우 중복 신청 안내를 표시한다.
- 신청자는 [참가신청 조회](/symposium/apply/search) 화면에서 신청 내용을 수정하거나 취소할 수 있다.
